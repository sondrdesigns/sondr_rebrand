`Button` — Sondr's outlined action control. Use for CTAs and secondary actions; the default is a hairline black box on paper.

```jsx
<Button href="#work">view works</Button>
<Button variant="solid" size="lg">get in touch</Button>
<Button variant="sticky">leave a note</Button>
```

Variants: `outline` (default hairline box), `solid` (ink fill), `sticky` (yellow post-it with lift shadow). Sizes: `sm` / `md` / `lg`. Labels are lowercase mono with wide tracking — keep copy short and unpunctuated.
