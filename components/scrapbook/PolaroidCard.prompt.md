`PolaroidCard` — a polaroid/instax frame for featured works and galleries.

```jsx
<PolaroidCard src="assets/work-1.jpg" caption="acme — 2025" tilt={-3} />
```

Props: `src` (photo), `caption`, `tilt`, `width`, `assetBase`, `onClick`. Hovering lifts the card. Lay several in a row with alternating tilts for the pinned-board look.
