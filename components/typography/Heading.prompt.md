`Heading` — Sondr's uppercase, wide-tracked display type.

```jsx
<Heading>crafting elevated digital experiences</Heading>
<Heading level="title">featured works</Heading>
<Heading level="heading" as="h3">our services</Heading>
```

Levels: `display` (96px hero), `title` (50px), `heading` (35px). Always uppercase with 0.11em tracking — the defining Sondr look. Pass `as` to change the semantic tag.
