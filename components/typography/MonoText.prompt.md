`MonoText` — body copy, labels and captions in Intel One Mono.

```jsx
<MonoText size="lead">we help businesses grow.</MonoText>
<MonoText>running paragraph copy, tracked wide.</MonoText>
<MonoText size="small" muted>est. 2024</MonoText>
```

Sizes: `lead` (20px), `body` (15px), `small` (13px). `muted` uses the soft ink color. All body text in Sondr is mono.
